## 📖 About Project

**WeatherInfo** is a simple and responsive Weather Application that provides **live weather information** for any city using the **WeatherAPI**.

Users can search for any city and instantly view:

- 🌍 City Name
- 🌡️ Current Temperature
- ☁️ Weather Condition
- 💧 Humidity
- 🌬️ Wind Speed
- ☁️ Cloud Percentage
- 🕒 Local Date & Time

The application also changes the **background image dynamically** according to the current weather condition such as Sunny, Cloudy, Rainy, etc.
