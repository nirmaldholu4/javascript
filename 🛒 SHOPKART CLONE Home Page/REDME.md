# ➡️ 🛒 SHOPKART CLONE - Simple E-Commerce Website

A simple Flipkart-style E-Commerce website built using **HTML, CSS, and JavaScript**.  
This project demonstrates product listing, search, sorting, add-to-cart functionality, and cart management using **LocalStorage**.

---

## 📌 Features

- 📱 Product Listing
- 🔍 Search Products by Company Name
- 📊 Sort Products
  - Price Low to High
  - Price High to Low
- 🛒 Add to Cart
- ❌ Remove Product from Cart
- 💾 LocalStorage Support
- 📱 Responsive Design
- 🎨 Flipkart-like UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- LocalStorage

## 🚀 How to Run

1. Download or Clone this repository.
2. Open the project folder.
3. Open **index.html** in your browser.
4. Browse products and add them to the cart.

---

## ⚙️ Functionalities

### 🏠 Home Page

- Display all products
- Search by company name
- Sort products by price
- Add products to cart

### 🛒 Cart Page

- View added products
- Remove products
- Automatically return to the main page if the cart becomes empty.
